# منصة إدارة المدرسة الابتدائية الطاهر صفر — حمام الأنف

منصة ويب خاصة بمدير المؤسسة: إسناد الأقسام، جداول الأوقات، دفتر المناداة، والعمل اليومي.
كل البيانات محفوظة **محليا في متصفح المدير** (localStorage) — لا خادم ولا اشتراك ولا تسريب للمعطيات.

---

## 1. تشغيل المنصة على حاسوبك (اختياري)

```bash
npm install
npm run dev
```
ثم افتح: http://localhost:3000

## 2. النشر على Vercel — خطوة بخطوة

1. أنشئ حسابا مجانيا على https://vercel.com (بحساب GitHub أو بالبريد).
2. أنشئ مستودعا جديدا على GitHub (مثلا `madrasa-taher-sfar`) وارفع فيه محتوى هذا المجلد:
   ```bash
   git init
   git add .
   git commit -m "أول نسخة من منصة المدرسة"
   git branch -M main
   git remote add origin https://github.com/<حسابك>/madrasa-taher-sfar.git
   git push -u origin main
   ```
3. في Vercel: **Add New → Project → Import** واختر المستودع.
4. اترك كل الإعدادات كما هي (Framework: Next.js) ثم **Deploy**.
5. بعد دقيقة يعطيك رابطا من نوع `https://madrasa-taher-sfar.vercel.app` — هذا رابط المنصة.

> بديل أسرع بلا GitHub: ثبّت `npm i -g vercel` ثم نفّذ `vercel` داخل المجلد واتبع الأسئلة.

## 3. أول ما تفعله بعد الفتح

1. **الإعدادات**: صحّح اسم المدرسة، المندوبية، السنة الدراسية، واسم المدير.
2. **الإعدادات → أوقات الحصص وأيام العمل**: طابقها مع توقيت المدرسة الحقيقي.
3. **الإعدادات → التوزيع الأسبوعي للساعات**: طابقه مع المنشور الرسمي لكل مستوى.
4. **الأقسام**: عدّل أسماء الأقسام والأعداد والقاعات ومعلم كل قسم.
5. **المعلمون**: أدخل الأسماء الحقيقية (23 معلما) وحدّد مجالات كل واحد ونصابه.
6. **الإسناد**: اضغط «إسناد آلي» ثم صحّح يدويا ما تراه مناسبا.
7. **جداول الأوقات**: اضغط «توليد الجداول» ثم صدّر الصور للنشر.
8. **الإعدادات → نسخة احتياطية**: نزّل ملف JSON كل أسبوع (هو كل أرشيف المدرسة).

## 4. الوحدات

| الوحدة | ما تفعله |
|---|---|
| لوحة القيادة | مؤشرات المدرسة، تنبيهات الإسناد، مهام اليوم، توازن نُصُب المعلمين |
| المعلمون | إدارة 23 معلما: الرتبة، الصنف، المجالات، النصاب، الساعات المسندة |
| الأقسام | 16 قسما: المستوى، العدد، القاعة، معلم القسم |
| الإسناد | محرك آلي يوزع المجالات على المعلمين + كشف التعارضات والفوارق |
| جداول الأوقات | توليد آلي، عرض بالقسم أو بالمعلم، تعديل يدوي، طباعة، تصدير PNG |
| دفتر المناداة | لصق قائمة التلاميذ، حضور يومي، تراكم الغيابات، طباعة الدفتر |
| العمل اليومي | مهام، زيارات صفية، غيابات الإطار، مراسلات — مع نماذج جاهزة |
| التعويض الذكي | عند غياب معلم: عرض حصصه واقتراح المعلمين المتفرغين في نفس التوقيت |
| النشر والفيسبوك | بطاقة صورة أنيقة (1:1) + نص منشور جاهز للنسخ |
| الإعدادات | المؤسسة، المجالات، التوقيت، النسخ الاحتياطية |

## 5. نظام التوقيت المعتمد (مطابق لجداول المدرسة)

- خمسة أيام: الاثنين → الجمعة.
- الحصص: 08-10 / 10-12 / 12-13 / 13-15 / 15-17 — حصة الساعتين تقبل مادتين (ساعة لكل مادة).
- نظام الفوجين: كل قسم صباحي أو مسائي في كل يوم — يُضبط من صفحة **الأقسام** (اضغط على اليوم لتغييره، أو استعمل «فوج أ» / «فوج ب» / «أيام كاملة»).
- المواد: عربية، رياضيات، إيقاظ علمي، تربية إسلامية، فرنسية، إنجليزية، تنشئة اجتماعية، تربية تشكيلية، تربية موسيقية، تربية تكنولوجية، تربية بدنية.
- اسم معلم الاختصاص يظهر داخل الخانة كما في جداولكم (مثال: تربية بدنية — رؤوف).

## 6. ملاحظات تقنية

- Next.js 15 (App Router) + Tailwind CSS، بالعربية واتجاه RTL.
- لا قاعدة بيانات: التخزين في متصفح المدير. للانتقال لاحقا إلى قاعدة بيانات مشتركة
  (عدة مستخدمين، دخول بكلمة سر) يكفي تعويض `lib/store.js` بواجهة Supabase أو Postgres.
- الملفات المهمة:
  - `lib/config.js` — التوقيت، المجالات، التوزيع الساعي، النصاب.
  - `lib/engine.js` — محرك الإسناد، مولّد الجداول، التعويض، المؤشرات.
  - `lib/store.js` — الحالة والتخزين المحلي.
  - `components/EmploiTable.js` — تصميم جدول الأوقات القابل للتصدير كصورة.
